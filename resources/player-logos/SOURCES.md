# 外部播放器图标来源

图标用于识别 Peach 外部播放菜单里的目标应用。各图标的权利归其所有者。PNG 保留原有造型和配色，按菜单显示尺寸缩小。

| 文件 | 来源 |
| --- | --- |
| `potplayer.png` | 从 Kakao [PotPlayer](https://potplayer.daum.net/) 已安装的 `PotPlayerMini64.exe` 提取应用图标。 |
| `vlc.png` | [VideoLAN 官方图标](https://images.videolan.org/images/VLC-IconSmall.png)。Copyright (c) 1996-2018 VideoLAN。用于识别 VLC，使用条件见 [VideoLAN 标识说明](https://docs.videolan.me/vlc-user/en/support/faq/legalconcerns.html#may-i-use-the-videolan-logo)。 |
| `mpv.png` | [mpv 官网](https://mpv.io/) 页首的 [应用图标](https://mpv.io/images/mpv-logo-128-0baae5aa.png)。 |
| `iina.png` | [IINA 官网应用图标](https://iina.io/img/icon.png)。 |
| `infuse.png` | Firecore 在 [App Store 上提供的 Infuse 图标](https://apps.apple.com/us/app/infuse/id1136220934)。 |
| `nplayer.png` | Newin Inc. 在 [App Store 上提供的 nPlayer 图标](https://apps.apple.com/us/app/nplayer/id1116905928)。 |
| `mxplayer.png` | 官方 [Google Play 商店上的 MX Player 图标](https://play.google.com/store/apps/details?id=com.mxtech.videoplayer.ad)。 |
