# 本地下载：把磁力交给 qBittorrent

Peach 可以把资源搜索得到的磁力交给 qBittorrent 下载。文件落在下载器所在的机器上，不经过 Peach；下载完成后 Peach 按以下两步登记：

```text
qBittorrent 保存目录/种子名 -> 对应媒体库目录 -> asset 行
```

Peach 与下载器可以在同一台机器，也可以跨机器。跨机器时 Peach 通过 SMB 媒体根或映射到本机盘符的 WebDAV 目录读取下载目录，对应关系见下一节。

## 前提

- qBittorrent 已开启 Web UI，Peach 能访问它的地址和端口（常见 `8085`）；
- qBittorrent 对保存目录有写权限；
- Peach 能读到同一个目录：同机直接读、Docker 读容器挂载、跨机读 SMB 共享或 WebDAV 映射盘符；
- 保存目录已经在 Peach 的「媒体库与入库」里声明为本地、SMB 或 WebDAV 映射盘符媒体根。

## 设置页

进入「配置 → 下载 → 本地下载」，填写：

| 字段 | 例子 | 说明 |
|---|---|---|
| qBittorrent 地址 | `http://192.0.2.10:8085` | 只写协议、主机和端口 |
| 用户名 | `admin` | qB Web UI 的登录账号 |
| 密码 | | 只写本机凭据文件；留空表示不改 |
| 下载器保存目录 | `/vol1/media/Peach` | qBittorrent 那台机器上的绝对路径 |
| 对应媒体库目录 | `R:\peach\...` | Peach 媒体库里对应的根目录，见下一节 |

点「检查」只登录并读取版本与默认保存目录，不提交任务；保存目录留空时会把 qB 的默认目录填回表单，点「保存配置」才落盘。保存后 qBittorrent 会出现在资源搜索弹层的「下载到」里。

同一个 infohash 已有任务时，Peach 接管那条任务，不重复提交；qB 里已有的任务也一样。

## 跨机器：SMB 或 WebDAV 盘符

Peach 和 qBittorrent 不在同一台机器时，可以任选一种：

- 给下载目录建 SMB 共享，在 Peach「配置 → 媒体库与入库」添加：

```text
来源：SMB 共享
路径：smb://192.0.2.10/media
账号：飞牛或 qB 所在机器的共享账号
```

- 或者先用 WebDAV/网络盘把下载目录挂成本机盘符，例如 `Z:\Downloads\Peach`，再按「本地目录」添加这个盘符路径；这种方式不需要 SMB。

保存后 Peach 会分配一个稳定的账本根目录，例如 `R:\peach\...`。把这个根目录填进「对应媒体库目录」，把 qB 的保存目录填进「下载器保存目录」。

落地时 Peach 会把 `保存目录/种子名` 的相对部分接到账本根目录，再通过 SMB 或本机 WebDAV 盘符读取实际文件。示例：

```text
qB 保存目录        /vol1/media/Peach
qB 完成任务        /vol1/media/Peach/ABC-123/ABC-123.mp4
账本路径           <Peach 账本根>\Peach\ABC-123\ABC-123.mp4
```

SMB 媒体根和网络映射盘符不加入本机文件监视，所以下载完成后由下载对账定向登记；全量扫描仍可作兜底。

## 状态与失败

| 状态 | 含义 |
|---|---|
| 已提交 | 已交给 qBittorrent |
| 下载中 | qB 与网盘离线下载共用这一格 |
| 下载完成 | 下载器报告完成 |
| 已入库 | 文件已进账本并绑定资产 |
| 失败 / 已取消 / 长时间未完成 | 按现有下载任务处理 |

失败分「配置或登录有误」「网盘拒绝下载该资源」「网络暂时不可用」等九类，只有网络类自动重试。qB 登录失败、Web API 不存在、目标目录权限不足都会在任务卡上给出原因。

## 已知限制

- 第一版只接受磁力，不接受种子上传、HTTP/FTP 直链和 ed2k；
- 取消只删 qB 任务，不删已下载或未完成的文件；
- qB 开启「完成后自动删除种子」时，Peach 在任务消失后按保存目录里的文件判定落地；如果文件也被清理，会报「目标目录中未找到下载文件」；
- 不要开启 qB 的自动种子管理或让分类改写到别的保存目录，否则映射会对不上；
- 飞牛系统自带的「下载」应用没有公开稳定的 REST API，本页只适用于应用中心的 qBittorrent 或 Docker 版 qB；
- qB 自签 HTTPS 需要有效证书；局域网 HTTP 更简单。

## 排查

| 现象 | 检查 |
|---|---|
| 设置页没有 qBittorrent 渠道 | 地址、账号、保存目录、媒体目录是否完整；qB Web UI 是否可达 |
| 任务提交后 qB 里没有 | qB 的 Web UI 日志、保存目录权限、磁力是否有效 |
| 完成但 Peach 没入库 | 「对应媒体库目录」是否就是本地/SMB/WebDAV 根；账号能否读到文件 |
| 入库到错误目录 | 检查 qB 是否改了保存路径；第一版要求保存目录本身对应媒体根 |
| 任务显示「网盘任务被删除」 | qB 是否清理了完成种子；检查文件是否还在保存目录 |
