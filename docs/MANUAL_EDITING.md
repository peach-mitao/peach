# 单片资料编辑与版本替换

## 编辑资料

打开一个本地在库视频，在详情区点击「编辑资料」。填写番号、文件名、作品标题和演员，也可选择 JPG、PNG 或静态 WebP 封面。多位演员用顿号或逗号分隔。选择图片只生成预览，点击「取消」不写入。

「番号」用于匹配作品身份、封面和在线资料，例如 `IPX-061`。修改番号后保存，会将当前视频文件名中的番号同步替换；文件名没有番号时加在开头，原有片名、分卷与版本标记保留。仅处理当前视频，扩展名沿用原格式。日期式编号的连字符与下划线分别保留，不互换作品身份。

「作品标题」只填写片名，番号填在单独的「番号」字段。填写标题不会改变抓取编号。手工确认的片名显示在馆藏卡片和详情中，包括尚未归属的条目；其他语言的来源标题不能遮盖人工片名。

封面区显示当前封面或所选图片预览，点击「选择封面」或「更换封面」从本机选图；「取消所选封面」恢复本次选择前的状态。

文件名可以省略后缀，保存时自动补齐原扩展名：MP4 仍为 `.mp4`，MKV 仍为 `.mkv`。文件名正文可包含点号；明确填写其他媒体格式的后缀会被拒绝。

打开编辑窗口时，当前播放器会释放视频，关闭窗口后按现有播放设置重新挂载。外部播放器或其他程序仍占用视频及配套文件时，保存会提示停止播放或关闭占用程序后重试，表单保留输入。

点击「保存资料」才执行以下操作：

- 按所填文件名在原目录改名，保留视频扩展名和视频内容。评分、收藏与播放记录继续属于同一条目。
- 私有的同名 NFO、配套图片与字幕随视频改名。其他版本共用的配套文件保留在原处，为当前版本生成独立副本；只调整当前版本的引用。共用 NFO 的视频需要先在表单中设置独立文件名，才能保存本片资料。目标重名时拒绝保存。
- 标题、番号与演员写入同名 `.nfo`；未编辑的 NFO 字段保留。演员也登记到现有实体和人工决定中，自动更新遵守现有人工字段保护。
- 所选封面转为同名 `-poster.jpg`，NFO 指向此图片，同时安装到现有封面缓存。所选原图片保持原样。同一番号的版本共用正式封面缓存。

保存失败时恢复本次文件变更，表单保留输入供修正后重试。其他页面已修改条目时，需重新打开表单读取当前值。

资料任务补入演员或标签后，先前打开的表单也需要重新读取，防止旧输入覆盖新资料。修正番号时，NFO 读取和写入共用身份判据，保留 IMDb 等其他体系标识；拟保存内容须能按相同解析器回读且身份唯一。

## 封面保存与删除

点击「保存资料」并成功后，图片会转换为 JPG，保存到视频旁的同名 `-poster.jpg`，同名 NFO 引用此副本；Peach 数据目录的 `generated/covers/` 同时保存用于显示的缓存。

- 删除最初从其他图库选择的原图片，不影响已经保存的封面。
- 删除视频旁的 `-poster.jpg`，当前缓存仍可显示；清理缓存或重建媒体库后，会失去这份本地恢复来源。
- 删除 Peach 的生成封面缓存，保留视频旁的图片和 NFO，可重新执行本地匹配恢复；两处都删除时，本地封面无法恢复。

建议将视频旁的 `-poster.jpg` 和 `.nfo` 随视频一起保留。只有选图、尚未保存成功时，不能将预览视为已经落盘。

## 文件名版本标记

版本标记继续由文件名推导，不保存第二套版本字段。

| 番号后的标记 | 显示徽章 |
| --- | --- |
| `C`、`r`、`R` | 中字 |
| `U` | 无码破解 |
| `UC` | 中字、无码破解 |
| `无修正`、`uncensored` | 无码破解 |

例如 `MDS-685r.mp4` 的作品身份为 `MDS-685`，显示「中字」。表单的版本开关改变时，用 `[中字]`、`[无码破解]` 写入文件名；直接填写文件名时沿用该文件名的现有解析规则。发行方本身的无码编号仍沿用原判据。

## 更新此视频

「更新此视频」启动现有资料任务，只处理当前条目。它重新读取本地 NFO 和配套图片，并重新询问已配置的资料来源；保留人工确认的字段与已有正式本地封面。完成后刷新当前卡片。其他资料任务运行期间，需要等待该任务结束。

更新提示显示当前番号或文件名。检查本地资料后仍无番号时，会提示先在「编辑资料」中填写番号。修改番号并保存后，再点击「更新此视频」查询对应资料。

该操作不改名，不移动或改写原视频、原图片；资料来源不可访问或没有收录时，仍会保留未取得的结果。

## 寻找更好版本

「寻找高清、无水印或完整版」是「高清版」页面的待办目标，保存在现有版本目标记录中，不是内容标签。它不会自动下载或覆盖旧文件。

1. 在「数据管理 → 高清版」找到目标，点击「查找资源」，使用现有资源搜索和下载入口。
2. 将找到的文件登记入库，在「查看版本」里核对画质、时长、字幕与内容，再决定保留哪个版本。
3. 同番号的新旧文件都在库时，两者作为不同版本保留，个人记录仍在各自条目上。目标已满足时，可取消寻找标记。
4. 若旧文件确已移出媒体目录，扫描和现有资源同步把旧记录标为「已消失」后，只有番号与候选能唯一对应，或时长能明确选中一个版本时，既有接回机制才会转接个人记录并关闭目标。无法确定的情况在孤儿记录中人工选择；演员、标签与配套文件不属于个人记录转接范围。

直接在磁盘上用同一路径覆盖视频会沿用该条目，但扫描不会自动清空已有时长和预览缓存，也不能证明内容相同。建议先作为独立版本入库核对，避免把旧缓存误当成新版的验收结果。
