# ADR-0174：显式映射的直链播放

## 背景

挂载网盘经过 Peach 转发原文件时，媒体流量经过服务端。已有 STRM 代理刻意隐藏上游地址；对希望终端直连的用户，这不能减少服务端流量。账本已有的资产身份、收藏与观看记录不能因为更换播放路径而重建。

## 决定

增加默认关闭的逐资产映射。映射同时校验资产 ID、来源和原始账本路径；配置由用户复核，不根据文件名自动绑定。请求通过现有鉴权后，Peach 使用播放器的 User-Agent 向显式配置的局域网 QMediaSync 地址请求 302，只将公网 HTTPS 跳转交给播放器。上游不可用或映射失效时沿用原有文件播放。映射不修改账本，删除映射即可停用。

此功能主动向获得播放权限的终端暴露短期直链，是 STRM 代理不外露上游地址规则的显式例外；链接可能被终端持有，不应写入日志或公开分享。跨域、播放器编解码支持及 115 的 User-Agent 策略须按客户端实测。仅覆盖 QMediaSync 的 115 原文件接口，不自动处理其他服务、转码画质或全库匹配。
