# ADR-0095：身份、职业与作品角色分开记录

状态：已接受。最后复核：2026-10-06。

`performer` 表示出演者，`creator` 表示发布账号，`studio` 表示发行机构。作品关系不直接断言职业、国籍或性别。日本 AV 与西方成人发行是可并存的发行市场，不是互斥的人物身份。

身份事实使用独立的多值来源断言：身份类型、职业、发行市场、账号角色。每条记录保留来源 URL、证据、置信度、核验时间与状态。目录推断和搜索命中保持 candidate；公开来源的确定事实使用 observed；用户复核才能 approved。

浏览分类是查询时生成的显示投影：艺人页为女优、素人、西方，允许同一个人同时命中多类。女优复用 `entry_links.JAV_DIRECTORIES` 的已绑定 performer id 或可信日本 AV 市场断言；素人按有效 FC2 出演作品或作品的素人标签分类；西方采用可信市场断言或作品发行地区。素人表示作品类型，不断言职业经历。MinnanoAV 的 production id、Stash 本机 id、Babepedia 的普通收录与候选不单独证明 JAV 身份。发布账号分为网黄博主、卖家、动画作者，后两类分别需要可信 seller、animator 断言。待核验是来源状态，不作为浏览分类。分类计数按搜索和有效作品计算，每类独立计数，筛选条隐藏空分类。

跨角色身份使用可撤回的 same_person 或 operates_account 关系。姓名相同不能自动建立关联，也不能自动合并实体；既有 id、别名、作品关系和行为历史保留。用户执行实体合并时来源断言随实体迁移，同来源冲突拒绝合并。

FC2 卖家名称仍遵守 ADR-0054 的候选 label 规则；有可核验账号证据才记录 seller。平台与合辑目录不能摄取为个人创作者。索引筛选在分页前执行，与资料页采用相同判据。资料页的分类带人物图标，排列在视频数量、事务所与别名左侧；完整来源断言由 API 保留，来源提示附在分类上。

复用 [Schema.org Person](https://schema.org/Person) 的职业与同一身份语义，以及 [Role](https://schema.org/Role) 的作品角色语义；使用 SQLite 来源表实现，不引入新的解析依赖。真实修复使用冻结计划、SQLite 备份与逐关系撤回回执。
