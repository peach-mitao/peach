# ADR-0097：定时拉取订阅每一轮都派补头像存量

- 状态：Accepted
- 日期：2026-10-09
- 修订：ADR-0053 第二条（存量补派的入口）

## 背景

`二の宮すずか` 09-22 建档，馆里只有一部合演 NHDTB-557。gfriends 图库里她名下有六张，来自六个目录；
不带参照跑一次 `match_gallery`，六张互相认得（ADR-0062），会装上 Moodyz 那张 600×783。
可她到现在都没有头像，`task_run` 里也没有她的 `entity-avatar` 一行。

补头像后继上线（09-24）时她已经建档，不算新实体，只能等存量补派。存量补派只在资料处理收尾时进行
（ADR-0053 第二条），而 09-30 之后一轮资料处理都没跑过：没有新片入库，就不会启动资料处理。
库里 146 位缺头像的女优一条都没派出去，她只有一部作品，排第 96 位。

## 决策

**`feed-check` 结算时也派补头像存量。** 订阅自己的后继排在前面，`MAX_FOLLOWUPS` 剩下的名额全给
`avatar_followup.stock`。排序和「试过又没变的不再派」（ADR-0053 第三条）都和资料处理收尾那一份
一样，两处派的是同一份存量，指纹记号也是同一份，同一个实体不会因为有两个入口就被试两次。

补头像不写账本，走自己的通道，和取资料、补别名那条写账本的通道不抢。补别名、补女优资料、
补厂牌这三份存量仍然只在资料处理收尾时派：它们要写账本，每条要问两三个站，配额由 ADR-0053 定。

## 后果

- 没有资料处理的日子，补头像存量也在推进。一轮大约 60 条，定时拉取一天两三轮，
  现有一百多位缺头像的女优几天内都能派完。
- 判据一个字没变：图库唯一命中、按脸比对、图库互证、封面截脸、馆外封面、小图兜底，各档照旧。
  试过却没装上的那些，指纹不变就不会被再派。
