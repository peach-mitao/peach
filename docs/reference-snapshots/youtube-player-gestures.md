## Peach 的差异

Peach 保留可配置步长、区域与长按倍速；已有更高倍速不会被长按降低。
用户请求的横滑每次十五秒属于 Peach 扩展，不是上述 YouTube 文档中的行为。
舞台播放器横滑只预览一个步长，松手定位；进度条仍用于任意位置定位。
沉浸模式已有任意位置长按倍速，本次保持其按内容坐标拖动进度的实现。
